# 🧾 Employee Management System

A full-stack Java Spring Boot application to manage employee data with CRUD functionality and MySQL integration.

---

## ✅ Features

- Add, view, update, and delete employees
- RESTful API using Spring Boot
- MySQL database integration
- Exception handling (optional step)
- Postman-tested endpoints
- (Upcoming) Swagger API documentation

---

## 🛠 Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Postman (for testing)

---

## 📂 Project Structure

com.example.employee_management_system
├── controller
├── service
├── repository
├── model
└── exception (to be added)


---

## 🚀 API Endpoints

| Method | Endpoint                | Description             |
|--------|-------------------------|-------------------------|
| POST   | `/api/employees`        | Create new employee     |
| GET    | `/api/employees`        | Get all employees       |
| GET    | `/api/employees/{id}`   | Get employee by ID      |
| PUT    | `/api/employees/{id}`   | Update employee         |
| DELETE | `/api/employees/{id}`   | Delete employee         |
