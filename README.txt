# Employee Management System

A full-stack Spring Boot application to manage employee data using REST APIs.

## Tech Stack
Java, Spring Boot, Spring Data JPA, MySQL, Swagger, (Planned: Spring Security with JWT)

## Features
- CRUD operations
- Search and filter
- Swagger documentation
- (Planned) JWT login

## Project Status
In Progress – June 2025
